2.1 每个功能模块的内部结构约定

所有功能模块遵循统一的内部目录结构约定：

  

子目录/文件 用途 必需

api/ RTK Query API Slice 定义 是

domain/ 纯函数领域逻辑 推荐

components/ 模块专用 UI 组件 推荐

views/ 页面级视图组件 是

hooks/ 自定义 Hooks 推荐

redux/ 本地状态 Slice 可选

types/ 模块类型定义 推荐

index.tsx 模块入口（导出页面组件） 是

domain.ts 领域逻辑 Barrel 导出 推荐

api.ts API Barrel 导出 参考这个供的完整项目结构，我希望未来按照这个进行调整，同时保证不改动页面样式和已经有的功能，仅仅重组不做代码破坏
